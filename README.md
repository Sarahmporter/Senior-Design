I HIGHLY reccommend using VSCode, since it has support for Git directly in the IDE. 

1. Do NOT code in the Main branch.
2. Ensure working branch is up to date before coding
3. Write meaningful commit messages 
4. Look over the VSCode_Tutorial word doc in the Google Drive if you are not 
familiar with Git/VSCode :)

Ask questions if you're confused! Please don't type random command lines if you 
don't know what they do.
